# Brand Enrich — Step 1: Scaffold — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployable app where invited team members sign in with a magic link, see contractor-sites' office look, manage the team, paste brand names, and watch each brand move through the seven research steps live (the steps are placeholders here; later plans fill them in).

**Architecture:** Next.js 16 (`cacheComponents`, React Compiler) on Vercel. Supabase Auth (magic link, invite-only) with contractor-sites' auth files. Prisma 7 + `@prisma/adapter-pg` for every read and write, server-side only; the browser's Supabase key reads no table. Inngest runs one job per brand; after each step the server broadcasts an ids-only message on a private Realtime channel and the page calls `router.refresh()`. UI is contractor-sites' `src/design` system plus shadcn on Base UI.

**Tech Stack:** Next.js 16.3.8, React 19.3.0, Tailwind 4, shadcn ^4.14 (style `base-mira`), @base-ui/react ^1.6, motion 12.43.0, lucide-react 1.52.0, next-themes ^0.4.6, Zod ^4.4, Prisma 7.4.2, pg ^8.16, @supabase/ssr ^0.12.4, @supabase/supabase-js ^2.112, Inngest ^4.18, Vitest ^4.1, pnpm 11.

**Spec:** `docs/superpowers/specs/2026-10-16-brand-enrich-design.md` — read §3, §4, §6, §8, §10, §12 and §13 before starting.

## Global Constraints

- Package manager pnpm (`packageManager: "pnpm@11.5.0"`); versions as in Tech Stack.
- Sign-in: Supabase Auth **magic link only**, **invite-only**; roles `owner` | `member` (spec §3, §8).
- Brand statuses exactly `queued`, `researching`, `needs_review`, `approved`, `exported`; research steps in order exactly `website`, `crawl`, `instagram`, `tiktok`, `images`, `campaigns`, `score` (spec §6).
- All data reads and writes go through server code via Prisma. The browser Supabase client is used for auth and Realtime only.
- Every `public` table has RLS enabled and `anon`/`authenticated` privileges revoked **per table**; never rely on `ALTER DEFAULT PRIVILEGES` alone (spec §12).
- Realtime payloads carry ids only; private channels; receive policy admits only rows in `public.users` (spec §8).
- `DATABASE_URL` = Transaction pooler (6543, `pgbouncer=true`) at runtime; `DIRECT_URL` (5432) for Prisma migrations only.
- No `@tailored/site-template` import anywhere (that package is private to contractor-sites).
- UI: design tokens only, no literal colours; `next/link` only, no raw `<a>` for internal links; use `src/design` components; add missing primitives with `pnpm dlx shadcn@latest add <name>`.
- Every server module (`scoped.ts`, `store.ts`, `broadcast.ts`, `prisma.ts`, server auth files) starts with `import "server-only"`; server actions live in `*actions.ts` files with `"use server"`, re-check permission on their first line, return `{ ok: true } | { ok: false; error: string }`, and never throw.
- Secrets are never printed, logged or committed; `.env*.local` stays git-ignored.
- Every commit message ends with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```

```ts
const LOCALE = "en-US";

/** "Oct 16" — the short date the design system's `sayAgo` falls back to after a week. */
export function formatShortDate(iso: string): string {
  const d = new Date(iso);
  if (Number.isNaN(d.getTime())) return "";
  return d.toLocaleDateString(LOCALE, { day: "numeric", month: "short" });
}
```

```ts
function sourceFiles(dir: string): string[] {
  return readdirSync(dir).flatMap((name) => {

    return /\.(ts|tsx|css)$/.test(name) ? [path] : [];
```

- [ ] **Step 2: Implement `src/lib/env.ts`**

```ts
/** A missing variable fails with its own name, not as `undefined` three calls later. */
export function requireEnv(name: string): string {
  const value = process.env[name];
  if (!value || value.trim() === "") throw new Error(`${name} is not set. See .env.example.`);
  return value;
}
```

```ts
import "server-only";
import { PrismaClient } from "@prisma/client";
import { PrismaPg } from "@prisma/adapter-pg";
import { Pool } from "pg";

/**
 * One Pool and one client per server instance, cached on globalThis so dev HMR doesn't open new
 * connections on every reload. DATABASE_URL is the Transaction pooler (6543); a Session-pooler URL
 * here exhausts pool_size under dev + HMR ("MaxClientsInSessionMode").
 *
 * Prisma connects as the table owner and bypasses RLS: every caller must resolve the member scope
 * first (src/lib/auth/scope.ts).
 */
const globalForPrisma = globalThis as unknown as { prisma?: PrismaClient; pool?: Pool };

const pool =
  globalForPrisma.pool ??
  new Pool({
    connectionString: process.env.DATABASE_URL || process.env.DIRECT_URL,
    max: Number(process.env.DATABASE_POOL_MAX || 5),
  });

export const prisma =
  globalForPrisma.prisma ??
  new PrismaClient({
    adapter: new PrismaPg(pool),
    log: process.env.NODE_ENV === "development" ? ["error", "warn"] : ["error"],
  });

if (process.env.NODE_ENV !== "production") {
  globalForPrisma.pool = pool;
  globalForPrisma.prisma = prisma;
}
```

```sql
-- The browser's Supabase key must read and write nothing in `public`. Prisma connects as the owner
-- and bypasses RLS; the app authorizes every request itself (src/lib/auth/scope.ts).
--
-- Driven from the catalog, not a hand-kept list, so it covers every table that exists. Per-table
-- REVOKE, not ALTER DEFAULT PRIVILEGES: default privileges have silently not applied on the
-- product database before. Any later migration that adds a table must re-run this block.
DO $$
DECLARE t text;
BEGIN
  FOR t IN SELECT tablename FROM pg_tables WHERE schemaname = 'public' AND tablename <> '_prisma_migrations' LOOP
    EXECUTE format('ALTER TABLE public.%I ENABLE ROW LEVEL SECURITY', t);
    EXECUTE format('REVOKE ALL ON public.%I FROM anon, authenticated', t);
  END LOOP;
END $$;

REVOKE ALL ON ALL SEQUENCES IN SCHEMA public FROM anon, authenticated;

-- Realtime: only team members may receive broadcasts on private channels.
CREATE OR REPLACE FUNCTION public.is_team_member()
RETURNS boolean
LANGUAGE sql
STABLE
SECURITY DEFINER
SET search_path = ''
AS $$
  SELECT EXISTS (SELECT 1 FROM public.users WHERE id = (SELECT auth.uid()))
$$;

REVOKE ALL ON FUNCTION public.is_team_member() FROM PUBLIC, anon;
GRANT EXECUTE ON FUNCTION public.is_team_member() TO authenticated;

DROP POLICY IF EXISTS "team_receives_broadcasts" ON realtime.messages;
CREATE POLICY "team_receives_broadcasts" ON realtime.messages
  FOR SELECT TO authenticated
  USING (public.is_team_member());
```

```ts
/**
 * Proves the browser key can read and write nothing. Run against the real project:
 *   pnpm verify:lockdown
 * Exits non-zero on any leak.
 */
import { config } from "dotenv";
config({ path: ".env.local" });

const TABLES = [
  "users", "invitations", "batches", "brands", "candidates",
  "selections", "campaigns", "campaign_images", "brand_text",
];

const url = process.env.NEXT_PUBLIC_SUPABASE_URL;
const key = process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY;
if (!url || !key) throw new Error("NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY must be set.");

const headers = { apikey: key, "Content-Type": "application/json" };
let leaks = 0;

for (const table of TABLES) {
  const read = await fetch(`${url}/rest/v1/${table}?select=*&limit=1`, { headers });
  const readBody = await read.text();
  const readLeaked = read.ok && readBody.trim() !== "[]";
  const write = await fetch(`${url}/rest/v1/${table}`, { method: "POST", headers, body: "{}" });
  const writeLeaked = write.ok;
  console.log(`${table.padEnd(16)} read ${read.status}${readLeaked ? " LEAK" : ""} · write ${write.status}${writeLeaked ? " LEAK" : ""}`);
  if (readLeaked || writeLeaked) leaks++;
}

if (leaks > 0) {
  console.error(`${leaks} table(s) reachable with the publishable key.`);
  process.exit(1);
}
console.log("Locked down: the publishable key reads and writes nothing.");
```

```ts
export type MemberRole = "owner" | "member";

export type Permission = "batches:read" | "batches:write" | "team:read" | "team:write";

const GRANTS: Record<MemberRole, readonly Permission[]> = {
  owner: ["batches:read", "batches:write", "team:read", "team:write"],
  member: ["batches:read", "batches:write", "team:read"],
};

export function can(role: MemberRole, permission: Permission): boolean {
```

```ts
/** Only a path on this site, and never back to /login or /auth; anything else falls back. */
export function safeNext(value: unknown, fallback = "/batches"): string {
  if (typeof value !== "string") return fallback;
  if (!value.startsWith("/") || value.startsWith("//") || value.startsWith("/\\")) return fallback;
  if (value === "/login" || value.startsWith("/login?") || value.startsWith("/auth/")) return fallback;
  return value;
}
```

```ts
import "server-only";
import { cache } from "react";
import { redirect } from "next/navigation";
import { prisma } from "@/lib/prisma";
import { currentSession } from "@/lib/auth/session";
import { can, type MemberRole, type Permission } from "@/lib/auth/roles";

declare const scopeBrand: unique symbol;

/**
 * Who is asking, resolved from the verified session and the users table. Branded so it can only be
 * produced here: every reader, store function and action takes a TeamScope, which proves the caller
 * was authenticated AND is a team member. Prisma bypasses RLS, so this is the authorization boundary.
 */
export type TeamScope = {
  readonly userId: string;
  readonly email: string;
  readonly role: MemberRole;
  readonly [scopeBrand]: true;
};

export const getTeamScope = cache(async (): Promise<TeamScope | null> => {
  const session = await currentSession();
  if (!session) return null;
  const user = await prisma.user.findUnique({
    where: { id: session.userId },
    select: { id: true, email: true, role: true },
  });
  if (!user) return null;
  return { userId: user.id, email: user.email, role: user.role } as TeamScope;
});

/** For pages and layouts: a signed-out visitor or a non-member goes to /login. */
export async function requireMember(): Promise<TeamScope> {
  const scope = await getTeamScope();
  if (!scope) redirect("/login");
  return scope;
}

export function scopeCan(scope: TeamScope, permission: Permission): boolean {
  return can(scope.role, permission);
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";
import { refreshSession } from "@/lib/auth/supabase-proxy";

/**
 * Keeps the Supabase session fresh and sends signed-out visitors to /login. It is NOT the
 * authorization boundary: pages and actions re-check membership through src/lib/auth/scope.ts.
 */
const PUBLIC_PREFIXES = ["/login", "/auth/", "/api/inngest"];

export async function proxy(request: NextRequest) {
  const { response, hasSession } = await refreshSession(request);
  const { pathname, search } = request.nextUrl;

  if (hasSession || PUBLIC_PREFIXES.some((p) => pathname === p || pathname.startsWith(p))) {
    return response;
  }
  if (pathname.startsWith("/api/")) {
    return NextResponse.json({ error: "Not signed in" }, { status: 401 });
  }
  const url = request.nextUrl.clone();
  url.pathname = "/login";
  url.search = `?next=${encodeURIComponent(pathname + search)}`;
  return NextResponse.redirect(url);
}

export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)"],
};
```

- [ ] **Step 2: Implement `src/lib/rate-limit.ts`**

```ts
/**
 * Fixed-window limiter, per server instance. Enough to stop a login form being hammered; not a
 * substitute for Supabase's own email rate limits, which still apply.
 */
const windows = new Map<string, { start: number; count: number }>();

export function rateLimit(
  key: string,
  limit: number,
  windowMs = 60_000,
  now = Date.now(),
): { ok: true } | { ok: false; retryAfterSeconds: number } {
  const w = windows.get(key);
  if (!w || now - w.start >= windowMs) {
    windows.set(key, { start: now, count: 1 });
    return { ok: true };
  }
  if (w.count < limit) {
    w.count++;
    return { ok: true };
  }
  return { ok: false, retryAfterSeconds: Math.ceil((w.start + windowMs - now) / 1000) };
}
```

```ts
export function normalizeEmail(email: string): string {

function pendingWhere(email: string) {
  return { email: normalizeEmail(email), acceptedAt: null, revokedAt: null, expiresAt: { gt: new Date() } };

/** Whether a magic link may CREATE an account for this email (shouldCreateUser). */
export async function hasPendingInvite(email: string): Promise<boolean> {
  return (await prisma.invitation.count({ where: pendingWhere(email) })) > 0;

/**
 * Runs on every sign-in. An existing member stays a member. A new account with a pending
 * invitation becomes a member with the invited role and the invitation is marked accepted.
 * Anyone else is not a member.
 */
export async function claimAccess(session: { userId: string; email: string | null }): Promise<"member" | "none"> {
  const existing = await prisma.user.findUnique({ where: { id: session.userId }, select: { id: true } });
  if (existing) return "member";
  if (!session.email) return "none";

  const invite = await prisma.invitation.findFirst({ where: pendingWhere(session.email), orderBy: { createdAt: "desc" } });
  if (!invite) return "none";

  await prisma.$transaction([
    prisma.user.create({ data: { id: session.userId, email: normalizeEmail(session.email), role: invite.role } }),
    prisma.invitation.update({ where: { id: invite.id }, data: { acceptedAt: new Date() } }),
  ]);
  return "member";
}
```

```ts
import { redirect } from "next/navigation";
import { authConfigured } from "@/lib/auth/config";
import { createSupabaseServerClient } from "@/lib/auth/supabase-server";

import { safeNext } from "@/lib/auth/safe-next";
import { rateLimit } from "@/lib/rate-limit";

type Result = { ok: true } | { ok: false; error: string };

/**
 * Always answers ok for a well-formed address, so the form can't be used to discover who has an
 * account. A new account can only be created when the email has a pending invitation.
 */
export async function requestMagicLink(email: string, next?: string): Promise<Result> {
  const address = normalizeEmail(email);
  if (!address || !address.includes("@") || address.length > 254) {
    return { ok: false, error: "That doesn't look like an email address." };
  }
  if (!authConfigured()) return { ok: false, error: "Sign-in isn't configured on this environment." };

  const h = await headers();
  const caller = h.get("x-forwarded-for")?.split(",")[0]?.trim() ?? "unknown";
  const limit = rateLimit(`login:${caller}`, 5);
  if (!limit.ok) return { ok: false, error: `Too many attempts. Try again in ${limit.retryAfterSeconds}s.` };

  const callback = new URL("/auth/callback", await requestOrigin());
  callback.searchParams.set("next", safeNext(next ?? null));

  const supabase = await createSupabaseServerClient();
  const { error } = await supabase.auth.signInWithOtp({
    email: address,
    options: { shouldCreateUser: await hasPendingInvite(address), emailRedirectTo: callback.toString() },
  });
  if (error) {
    console.error("[auth] magic link failed:", error.message);
    if (process.env.NODE_ENV === "development") return { ok: false, error: error.message };
  }
  return { ok: true };
}

export async function signOut(): Promise<void> {
  const supabase = await createSupabaseServerClient();
  await supabase.auth.signOut();
  redirect("/login");
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { getTeamScope, scopeCan } from "@/lib/auth/scope";
import type { MemberRole } from "@/lib/auth/roles";
import { removalProblem, roleChangeProblem } from "@/lib/team/rules";
import { createInvitation, deleteMember, findMember, isMemberEmail, ownerCount, revokeInvitationById, setMemberRole } from "@/lib/team/store";

type Result = { ok: true } | { ok: false; error: string };
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
const ROLES: MemberRole[] = ["owner", "member"];

export async function inviteMember(email: string, role: MemberRole): Promise<Result> {
  const scope = await getTeamScope();
  if (!scope || !scopeCan(scope, "team:write")) return { ok: false, error: "Only owners can invite people." };
  const address = email.trim().toLowerCase();
  if (!address.includes("@") || address.length > 254) return { ok: false, error: "That doesn't look like an email address." };
  if (!ROLES.includes(role)) return { ok: false, error: "Pick a role." };
  if (await isMemberEmail(address)) return { ok: false, error: "That person is already on the team." };
  await createInvitation(scope, address, role);
  revalidatePath("/team");
  return { ok: true };
}

export async function revokeInvitation(id: string): Promise<Result> {
  const scope = await getTeamScope();
  if (!scope || !scopeCan(scope, "team:write")) return { ok: false, error: "Only owners can revoke invitations." };
  if (!UUID.test(id)) return { ok: false, error: "That invitation doesn't exist." };
  await revokeInvitationById(scope, id);
  revalidatePath("/team");
  return { ok: true };
}

export async function removeMember(userId: string): Promise<Result> {
  const scope = await getTeamScope();
  if (!scope || !scopeCan(scope, "team:write")) return { ok: false, error: "Only owners can remove people." };
  if (!UUID.test(userId)) return { ok: false, error: "That person isn't on the team." };
  const target = await findMember(userId);
  if (!target) return { ok: false, error: "That person isn't on the team." };
  const problem = removalProblem({ actorId: scope.userId, targetId: target.id, targetRole: target.role, ownerCount: await ownerCount() });
  if (problem) return { ok: false, error: problem };
  await deleteMember(scope, target.id);
  revalidatePath("/team");
  return { ok: true };
}

export async function changeMemberRole(userId: string, role: MemberRole): Promise<Result> {
  const scope = await getTeamScope();
  if (!scope || !scopeCan(scope, "team:write")) return { ok: false, error: "Only owners can change roles." };
  if (!UUID.test(userId) || !ROLES.includes(role)) return { ok: false, error: "That change isn't valid." };
  const target = await findMember(userId);
  if (!target) return { ok: false, error: "That person isn't on the team." };
  const problem = roleChangeProblem({ actorId: scope.userId, targetId: target.id, from: target.role, to: role, ownerCount: await ownerCount() });
  if (problem) return { ok: false, error: problem };
  await setMemberRole(scope, target.id, role);
```

```ts
export const MAX_BRANDS_PER_BATCH = 50;

export type ParsedBrand = { name: string; websiteHint: string | null };

/** A hostname with at least one dot and no spaces, optionally with scheme and path. */
const LOOKS_LIKE_WEBSITE = /^(https?:\/\/)?[a-z0-9-]+(\.[a-z0-9-]+)+(:\d+)?(\/\S*)?$/i;

function toUrl(hint: string): string | null {
  try {
    return new URL(/^https?:\/\//i.test(hint) ? hint : `https://${hint}`).toString();
  } catch {
    return null;
  }
}

/** Brand names can contain commas ("Dear, Klairs"); only a trailing website counts as a hint. */
function splitLine(line: string): ParsedBrand {
  const lastComma = line.lastIndexOf(",");
  if (lastComma > 0) {
    const tail = line.slice(lastComma + 1).trim();
    const url = LOOKS_LIKE_WEBSITE.test(tail) ? toUrl(tail) : null;
    if (url) return { name: line.slice(0, lastComma).trim(), websiteHint: url };
  }
  return { name: line.trim(), websiteHint: null };
}

export function parseBatchInput(text: string): { brands: ParsedBrand[]; errors: string[] } {
  const brands: ParsedBrand[] = [];
  const errors: string[] = [];
  const seen = new Set<string>();

  text.split(/\r?\n/).forEach((raw, i) => {
    const line = raw.trim();
    if (!line) return;
    const brand = splitLine(line);
    const key = brand.name.toLowerCase();
    if (seen.has(key)) {
      errors.push(`Line ${i + 1}: "${brand.name}" is already in this batch.`);
      return;
    }
    seen.add(key);
    brands.push(brand);
  });

  if (brands.length > MAX_BRANDS_PER_BATCH) {
    return { brands: [], errors: [`At most ${MAX_BRANDS_PER_BATCH} brands per batch.`] };
  }
  return { brands, errors };
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { getTeamScope, scopeCan } from "@/lib/auth/scope";
import { parseBatchInput } from "@/lib/batches/parse-input";
import { createBatchWithBrands } from "@/lib/batches/store";
import { inngest } from "@/lib/inngest/client";
import { brandResearchEvent } from "@/lib/inngest/events";

export async function startBatch(text: string): Promise<{ ok: true; batchId: string } | { ok: false; error: string }> {
  const scope = await getTeamScope();
  if (!scope || !scopeCan(scope, "batches:write")) return { ok: false, error: "You can't start research." };

  const { brands, errors } = parseBatchInput(text);
  if (errors.length > 0) return { ok: false, error: errors.join("\n") };
  if (brands.length === 0) return { ok: false, error: "Paste at least one brand name." };

  const { batchId, brandIds } = await createBatchWithBrands(scope, brands);
  try {
    await inngest.send(brandIds.map(brandResearchEvent));
  } catch (error) {
    console.error("[batches] could not queue research", error);
    return { ok: false, error: "The batch was saved but research couldn't start. Try again in a minute." };
  }
  revalidatePath("/batches");
  return { ok: true, batchId };
}
```

```tsx
"use client";

import { useEffect, useRef } from "react";
import type { RealtimeChannel } from "@supabase/supabase-js";
import { useRouter } from "next/navigation";
import { createSupabaseBrowserClient } from "@/lib/auth/supabase-browser";
import { BRAND_EVENTS, batchTopic } from "@/lib/realtime/channels";

/**
 * Listens on the batch's private channel and re-renders from the server on every change. The
 * message carries ids only; nothing shown comes from Realtime. Refreshes are coalesced so 25
 * brands finishing steps at once cause a handful of renders, not hundreds.
 */
export function BatchLive({ batchId }: { batchId: string }) {
  const router = useRouter();
  const routerRef = useRef(router);
  useEffect(() => {
    routerRef.current = router;
  }, [router]);

  useEffect(() => {
    const supabase = createSupabaseBrowserClient();
    let channel: RealtimeChannel | null = null;
    let cancelled = false;
    let timer: ReturnType<typeof setTimeout> | null = null;

    const refreshSoon = () => {
      if (timer) return;
      timer = setTimeout(() => {
        timer = null;
        routerRef.current.refresh();
      }, 400);
    };

    void (async () => {
      await supabase.realtime.setAuth();
      if (cancelled) return;
      channel = supabase.channel(batchTopic(batchId), { config: { private: true } });
      channel.on("broadcast", { event: BRAND_EVENTS.CHANGED }, refreshSoon);
      channel.subscribe((status, error) => {
        if (status === "CHANNEL_ERROR" || status === "TIMED_OUT" || status === "CLOSED") {
          console.warn("[realtime] batch channel", status, error?.message ?? "");
        }
      });
    })();

    return () => {
      cancelled = true;
      if (timer) clearTimeout(timer);
      if (channel) void supabase.removeChannel(channel);
    };
  }, [batchId]);

  return null;
}
```
