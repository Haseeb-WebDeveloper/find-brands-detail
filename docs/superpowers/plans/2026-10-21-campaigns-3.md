# Brand Enrich — Step 3: Campaigns — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The research job's `campaigns` step proposes up to 8 of the brand's visual campaigns, most recent first, each with a title, date, source pages that really load, a description of at most 500 characters written from those pages, and checked images (brand-owned first, third-party labelled) with one selected; the brand page shows them as cards for review.

**Architecture:** A web-searching model lists campaigns and their source pages; the app fetches every source (a campaign with no page that loads is dropped: nothing without a source), pulls candidate images from each page (og:image, twitter:image, large article images) and from the brand's Instagram posts whose captions name the campaign, checks every image with the importer's check (campaign slot, 800 px), scores and chooses one per campaign, then asks a plain (no-search) model to write each description from the fetched page text, re-asking once when one runs over 500 characters. The model chain (Groq first, Gemini fallback) moves out of the website step into `src/lib/ai/models.ts` so both steps share it.

**Tech Stack:** Vercel AI SDK, `@ai-sdk/groq` (`openai/gpt-oss-120b`, `browser_search`), `@ai-sdk/google` fallback, cheerio, 2d's image check, Prisma 7, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-brand-enrich-design.md` — §3 (campaign definition, recency, images), §5 `campaigns`, §6 step 6 and tables `campaigns`/`campaign_images`, §7 Campaigns, §8 brand review cards.

### Probe (2026-10-21, TIRTIR)

`gpt-oss-120b` + `browser_search`, reasoning effort **low**: 21 s, 4 campaigns ("V&YOU: Let's Radiate" 2025-11, "World Tour; The First Light" 2025-10, …) with source URLs. 3 of 4 sources loaded with og:images of 1080×1080, 1600×900; one URL was a 404 (invented). Effort "medium" timed out at 180 s. So: low effort, every source fetched, unreachable sources dropped.

The DB importer (db-admin `brand-import.ts`) takes 3–8 campaigns, each `title`, `description` (≤ 500 chars), one image URL (campaign slot ≥ 800 px, filled to 200:236). Existing DB descriptions are short editorial reads: what the campaign shows and why it matters for the brand.

## Global Constraints

- All earlier constraints apply (`AGENTS.md`). No schema change: `campaigns`, `campaign_images`, `CampaignStatus`, `ImageSourceKind` exist.
- Campaign definition (spec §3): distinct visual campaigns — ambassadors, collaborations, seasonal campaigns, hero product launches with campaign imagery, pop-ups; skip sales, retail expansion, promotions without imagery. No age limit; most recent first; at most 8 (`position` 1–8).
- Every campaign is `proposed` (reviewed by a person, spec §7). A campaign is kept only if at least one source page loads or an Instagram post matches it.
- Images: brand-owned (brand's domains, a domain carrying the brand's name, brand Instagram) first; others labelled `third_party` and never better than **review**. Rejected below 800 px or not an image. Instagram CDN links expiring within 7 days → review. At most 5 image checks per campaign, one at a time.
- Descriptions: written only from the fetched pages' text; over 500 characters → re-requested shorter once; still over → cut at the last sentence end within 500. Target 300–450 characters, the DB's editorial tone, no marketing superlatives.
- Social pages (Instagram, TikTok, Facebook, X, YouTube) are never fetched as sources.

```ts
import "server-only";
import { noLog, type ResearchLog } from "@/lib/research/log-types";

type Effort = "low" | "medium";
const TIMEOUT_MS = 120_000;
const message = (error: unknown) => (error instanceof Error ? error.message : String(error));

/**
 * Web-searching models, tried in order (contractor-sites' chain): Groq first, Gemini when Groq has
 * no key, errors or hits its quota. Search-grounded calls cannot also enforce a JSON schema, so
 * callers ask for JSON in the prompt and validate it.
 */
const SEARCHERS: { label: string; ready: () => boolean; run: (prompt: string, effort: Effort) => Promise<string> }[] = [
  {
    label: "Groq",
    ready: () => Boolean(process.env.GROQ_API_KEY),
    run: async (prompt, effort) => {
      const { generateText } = await import("ai");
      const { groq } = await import("@ai-sdk/groq");
      const ask = async () =>
        (
          await generateText({
            model: groq("openai/gpt-oss-120b"),
            tools: { browser_search: groq.tools.browserSearch({}) },
            providerOptions: { groq: { reasoningEffort: effort, reasoningFormat: "hidden" } },
            abortSignal: AbortSignal.timeout(TIMEOUT_MS),
            prompt,
          })
        ).text;
      try {
        return await ask();
      } catch (error) {
        // The model now and then calls a tool that doesn't exist ("json"), which Groq rejects
        // outright. A second try almost always answers.
        if (!/tool call validation failed/i.test(message(error))) throw error;
        return ask();
      }
    },
  },
  {
    label: "Gemini",
    ready: () => Boolean(process.env.GOOGLE_GENERATIVE_AI_API_KEY),
    run: async (prompt) => {
      const { generateText } = await import("ai");
      const { google } = await import("@ai-sdk/google");
      const { text } = await generateText({
        model: google("gemini-2.5-flash"),
        tools: { google_search: google.tools.googleSearch({}) },
        abortSignal: AbortSignal.timeout(TIMEOUT_MS),
        prompt,
      });
      return text;
    },
  },
];

/**
 * Asks each searching model in turn until one answers with text `accept` takes. Never throws: no
 * key or every model failing is `null`, and the caller sends the brand to review.
 */
export async function askWithSearch(
  prompt: string,
  { what, effort, log = noLog, accept = () => true }: { what: string; effort: Effort; log?: ResearchLog; accept?: (text: string) => boolean },
): Promise<string | null> {
  for (const s of SEARCHERS.filter((x) => x.ready())) {
    try {
      await log(`Searching the web for ${what} with ${s.label}. This can take a minute…`);
      const text = await s.run(prompt, effort);
      if (accept(text)) return text;
      await log(`${s.label} found nothing usable.`, "warn");
    } catch (error) {
      console.error(`[ai] ${s.label} search failed`, error);
      const quota = /quota|rate.?limit|429/i.test(message(error));
      await log(`${s.label} search ${quota ? "is over its daily limit" : "failed"}.`, "warn");
    }
  }
  return null;
}

/** A plain (no search) answer for writing and extraction: Groq, then Gemini. Never throws. */
export async function askPlain(prompt: string): Promise<string | null> {
  const { generateText } = await import("ai");
  if (process.env.GROQ_API_KEY) {
    try {
      const { groq } = await import("@ai-sdk/groq");
      return (await generateText({ model: groq("openai/gpt-oss-120b"), providerOptions: { groq: { reasoningEffort: "low", reasoningFormat: "hidden" } }, abortSignal: AbortSignal.timeout(TIMEOUT_MS), prompt })).text;
    } catch (error) {
      console.error("[ai] Groq writing failed", error);
    }
  }
  if (process.env.GOOGLE_GENERATIVE_AI_API_KEY) {
    try {
      const { google } = await import("@ai-sdk/google");
      return (await generateText({ model: google("gemini-2.5-flash"), abortSignal: AbortSignal.timeout(TIMEOUT_MS), prompt })).text;
    } catch (error) {
      console.error("[ai] Gemini writing failed", error);
    }
  }
  return null;
}
```

```ts
import { z } from "zod";

export type FoundCampaign = { title: string; date: string | null; sources: string[] };

const Answer = z.object({
  campaigns: z.array(z.object({ title: z.string(), date: z.string().nullish(), sources: z.array(z.string()).catch([]) })),
});
const SOCIAL = /(^|\.)(instagram|tiktok|facebook|youtube|youtu|x|twitter|threads|pinterest)\.[a-z.]+$/i;
const MAX = 8;

export function campaignsPrompt({ brand, site, instagram }: { brand: string; site: string | null; instagram: string | null }): string {
  const about = [site ? `official site ${site}` : null, instagram ? `Instagram @${instagram}` : null].filter(Boolean).join(", ");
  return (
    `List the visual marketing campaigns of the beauty brand "${brand}"${about ? ` (${about})` : ""}, most recent first, up to ${MAX}. ` +
    `A campaign has distinct campaign imagery: ambassadors, collaborations, seasonal campaigns, hero product launches with campaign visuals, pop-ups. ` +
    `Skip sales, discounts, retail expansion and promotions without imagery. ` +
    `For each give: title (short, as the brand names it), date (YYYY-MM, or null), and sources: up to 3 URLs of pages that show the campaign imagery, ` +
    `the brand's own pages first (site, press release), then press articles. Only URLs you actually found; no social media links. ` +
    `Answer with JSON only: {"campaigns":[{"title":"...","date":"YYYY-MM","sources":["https://..."]}]}`
  );
}

/** The model's list, validated: real-looking URLs only, no social pages, no repeats, at most 8. */
export function parseCampaignsAnswer(text: string): FoundCampaign[] {
  const json = text.match(/\{[\s\S]*\}/)?.[0];
  if (!json) return [];
  let parsed: z.infer<typeof Answer>;
  try {
    parsed = Answer.parse(JSON.parse(json));
  } catch {
    return [];
  }
  const out: FoundCampaign[] = [];
  for (const c of parsed.campaigns) {
    const title = c.title.trim();
    if (!title || out.some((o) => o.title.toLowerCase() === title.toLowerCase())) continue;
    const sources = c.sources.flatMap((s) => {
      try {
        const u = new URL(s);
        return /^https?:$/.test(u.protocol) && !SOCIAL.test(u.hostname) ? [u.toString()] : [];
      } catch {
        return [];
      }
    });
    const date = c.date && /^\d{4}(-\d{2})?$/.test(c.date.trim()) ? c.date.trim() : null;
    out.push({ title, date, sources: [...new Set(sources)].slice(0, 3) });
    if (out.length === MAX) break;
  }
  return out;
}
```

```ts
import * as cheerio from "cheerio";

const SKIP = /\.(svg|gif)(\?|$)|^data:|logo|icon|avatar|sprite|placeholder|spacer|pixel|badge/i;
const MAX_IMAGES = 4;
const MAX_TEXT = 1_500;

function absolute(href: string | undefined, base: string): string | null {
  if (!href) return null;
  try {
    return new URL(href.trim(), base).toString();
  } catch {
    return null;
  }
}

/** The largest candidate of a srcset ("a.jpg 400w, b.jpg 1600w" → b.jpg). */
function largest(srcset: string): string | undefined {
  return srcset
    .split(",")
    .map((part) => part.trim().split(/\s+/))
    .map(([u, w]) => ({ u, w: Number.parseFloat(w ?? "0") || 0 }))
    .sort((a, b) => b.w - a.w)[0]?.u;
}

/** What a campaign's source page offers: its share images and article images, and text to describe it from. */
export function readCampaignPage(html: string, url: string): { images: string[]; text: string } {
  const $ = cheerio.load(html);
  const found: (string | null)[] = [
    absolute($('meta[property="og:image"]').attr("content"), url),
    absolute($('meta[name="twitter:image"]').attr("content") ?? $('meta[property="twitter:image"]').attr("content"), url),
  ];
  const body = $("article, main").length > 0 ? $("article img, main img") : $("body img");
  body.each((_, el) => {
    const img = $(el);
    found.push(absolute((img.attr("srcset") && largest(img.attr("srcset") ?? "")) ?? img.attr("src") ?? img.attr("data-src"), url));
  });
  const images = [...new Set(found.filter((u): u is string => Boolean(u) && !SKIP.test(u as string)))].slice(0, MAX_IMAGES);

  const paragraphs = $("article p, main p").length > 0 ? $("article p, main p") : $("p");
  const text = [$("title").first().text(), $('meta[name="description"]').attr("content") ?? "", ...paragraphs.toArray().map((p) => $(p).text())]
    .map((t) => t.replace(/\s+/g, " ").trim())
    .filter(Boolean)
    .join("\n")
    .slice(0, MAX_TEXT);
  return { images, text };
}
```

```ts
import { compactName } from "@/lib/website/domain";

/** Words that appear in every beauty caption, so they don't identify a campaign. */
const STOP = new Set(["with", "from", "your", "this", "that", "launch", "campaign", "collection", "edition", "glow", "skin", "beauty", "care", "skincare", "makeup", "official", "global", "new", "the", "and", "for"]);

/** Recent brand posts whose caption names the campaign: brand-owned imagery for it. */
export function matchPosts(title: string, brand: string, posts: { mediaUrl: string | null; caption: string | null; mediaType: string }[]): string[] {
  const own = compactName(brand);
  const words = title
    .toLowerCase()
    .split(/[^a-z0-9à-ɏ]+/)
    .filter((w) => w.length >= 4 && !STOP.has(w) && compactName(w) !== own);
  if (words.length === 0) return [];
  return posts
    .filter((p) => p.mediaType !== "VIDEO" && p.mediaUrl && p.caption)
    .filter((p) => words.some((w) => (p.caption ?? "").toLowerCase().includes(w)))
    .map((p) => p.mediaUrl as string)
    .slice(0, 2);
}
```

```ts
import { z } from "zod";

export const DESCRIPTION_MAX = 500;
const TARGET = 450;

/**
 * One call for all of a brand's campaigns, written only from the text of their source pages, in the
 * DB's voice: what the campaign shows, then why it matters for the brand.
 */
export function describePrompt(brand: string, items: { title: string; date: string | null; text: string }[]): string {
  const blocks = items.map((c, i) => `${i + 1}. ${c.title}${c.date ? ` (${c.date})` : ""}\nSource text:\n${c.text}`).join("\n\n");
  return (
    `You write campaign notes for a beauty-industry database. For each campaign of the brand "${brand}" below, write one description ` +
    `of 300 to ${TARGET} characters (at most ${TARGET} characters): first what the campaign shows (who, the visual idea, the setting), ` +
    `then why it matters for the brand. Plain, analytical English; no hashtags, no emojis, no marketing superlatives. ` +
    `Use only facts from the source text; if it says too little, write less rather than invent. ` +
    `Answer with JSON only: {"descriptions":["...", "..."]} in the same order.\n\n${blocks}`
  );
}

export function shortenPrompt(brand: string, title: string, description: string): string {
  return `Shorten this description of ${brand}'s campaign "${title}" to at most ${TARGET} characters, keeping its facts and tone. Answer with the text only.\n\n${description}`;
}

const Answer = z.object({ descriptions: z.array(z.string().nullish()) });

export function parseDescriptions(text: string, count: number): (string | null)[] {
  const empty = Array.from({ length: count }, () => null);
  const json = text.match(/\{[\s\S]*\}/)?.[0];
  if (!json) return empty;
  try {
    const { descriptions } = Answer.parse(JSON.parse(json));
    return empty.map((_, i) => descriptions[i]?.trim() || null);
  } catch {
    return empty;
  }
}

/** The last resort for a description still too long after re-asking: whole sentences only. */
export function cutToSentence(text: string, max = DESCRIPTION_MAX): string {
  if (text.length <= max) return text;
  const head = text.slice(0, max);
  const end = Math.max(head.lastIndexOf(". "), head.lastIndexOf("! "), head.lastIndexOf("? "), head.endsWith(".") ? head.length - 1 : -1);
  return end > 0 ? head.slice(0, end + 1) : head.slice(0, head.lastIndexOf(" ")).trim();
}
```

```ts
import type { FetchedPage } from "@/lib/website/judge";
import type { ImageCheckResult } from "@/lib/images/check-image";
import { linkExpiry } from "@/lib/images/expiry";
import { chooseImage, scoreImage, type ImageCandidate, type ImageSource, type ImageVerdict } from "@/lib/images/score";
import { domainMatchesBrand, registrableDomain } from "@/lib/website/domain";
import { campaignsPrompt, parseCampaignsAnswer } from "@/lib/campaigns/find";
import { readCampaignPage } from "@/lib/campaigns/page";
import { matchPosts } from "@/lib/campaigns/posts";
import { cutToSentence, DESCRIPTION_MAX, describePrompt, parseDescriptions, shortenPrompt } from "@/lib/campaigns/describe";
import { noLog, type ResearchLog } from "@/lib/research/log-types";

type Post = { mediaUrl: string | null; caption: string | null; mediaType: string };
export type CampaignsInput = { brand: string; site: string | null; brandDomains: string[]; instagram: { handle: string; posts: Post[] } | null };
export type CampaignsDeps = {
  search(prompt: string, log: ResearchLog): Promise<string | null>;
  write(prompt: string): Promise<string | null>;
  fetchPage(url: string): Promise<FetchedPage>;
  checkImage(url: string): Promise<ImageCheckResult>;
};
export type ResearchedCampaign = {
  title: string;
  date: string | null;
  description: string;
  /** Set when the description needs a closer look: cut to fit, or nothing to write it from. */
  descriptionNote: string | null;
  sources: string[];
  images: { candidate: ImageCandidate; verdict: ImageVerdict }[];
  chosen: ImageCandidate | null;
};

const MAX_CHECKS = 5;
const host = (url: string) => new URL(url).hostname.replace(/^www\./, "");

export async function researchCampaigns(input: CampaignsInput, deps: CampaignsDeps, log: ResearchLog = noLog, now = new Date()): Promise<ResearchedCampaign[]> {
  const text = await deps.search(campaignsPrompt({ brand: input.brand, site: input.site, instagram: input.instagram?.handle ?? null }), log);
  const found = text ? parseCampaignsAnswer(text) : [];
  if (found.length === 0) {
    await log("No campaigns found. Add them by hand during review.", "warn");
    return [];
  }
  await log(`Found ${found.length} possible campaign${found.length === 1 ? "" : "s"}: ${found.map((c) => c.title).join(", ")}.`);

  const owned = (url: string) => {
    const h = new URL(url).hostname;
    return input.brandDomains.includes(registrableDomain(h)) || domainMatchesBrand(h, input.brand);
  };
  const kept: (Omit<ResearchedCampaign, "description" | "descriptionNote"> & { text: string })[] = [];
  for (const c of found) {
    // Every source is fetched: the model sometimes names pages that don't exist.
    const pages: { url: string; images: string[]; text: string }[] = [];
    for (const url of c.sources) {
      const p = await deps.fetchPage(url);
      if (p.ok) pages.push({ url, ...readCampaignPage(p.html, p.finalUrl ?? url) });
    }
    const posts = input.instagram ? matchPosts(c.title, input.brand, input.instagram.posts) : [];
    if (pages.length === 0 && posts.length === 0) {
      await log(`Dropped "${c.title}": none of its source pages loaded.`, "warn");
      continue;
    }
    // Brand-owned images first (spec §3), then third-party pages.
    const leads: { url: string; source: ImageSource }[] = [];
    for (const p of [...pages].sort((a, b) => Number(owned(b.url)) - Number(owned(a.url)))) {
      const source: ImageSource = owned(p.url) ? { kind: "site", label: host(p.url) } : { kind: "third_party", label: host(p.url) };
      for (const u of p.images) leads.push({ url: u, source });
    }
    for (const u of posts) leads.push({ url: u, source: { kind: "instagram", label: `a @${input.instagram?.handle} post` } });
    const images: ResearchedCampaign["images"] = [];
    for (const lead of leads.filter((l, i, all) => all.findIndex((x) => x.url === l.url) === i).slice(0, MAX_CHECKS)) {
      const check = await deps.checkImage(lead.url);
      const candidate: ImageCandidate = { slot: "campaign", url: lead.url, source: lead.source, check, expiresAt: linkExpiry(lead.url) };
      images.push({ candidate, verdict: scoreImage(candidate, now) });
    }
    const chosen = chooseImage(images);
    const verdict = images.find((i) => i.candidate === chosen)?.verdict;
    await log(
      `"${c.title}"${c.date ? ` (${c.date})` : ""}: ${chosen && verdict ? `image ${verdict.reason}` : "no usable image yet."}`,
      verdict?.score === "proven" ? "good" : "warn",
    );
    kept.push({ title: c.title, date: c.date, sources: pages.map((p) => p.url), images, chosen, text: pages.map((p) => p.text).join("\n\n") || `Instagram post caption mentioning ${c.title}.` });
  }
  if (kept.length === 0) return [];

  await log("Writing the campaign descriptions…");
  const written = parseDescriptions((await deps.write(describePrompt(input.brand, kept))) ?? "", kept.length);
  const out: ResearchedCampaign[] = [];
  for (const [i, c] of kept.entries()) {
    let description = written[i] ?? "";
    let descriptionNote: string | null = description ? null : "Nothing to write from yet. Write it during review.";
    if (description.length > DESCRIPTION_MAX) {
      // Spec §7: over the limit is re-requested shorter before review.
      const shorter = (await deps.write(shortenPrompt(input.brand, c.title, description)))?.trim() ?? "";
      description = shorter && shorter.length <= DESCRIPTION_MAX ? shorter : cutToSentence(shorter || description);
      if (!(shorter && shorter.length <= DESCRIPTION_MAX)) descriptionNote = "Shortened to fit 500 characters; check the ending.";
    }
    const { text: _text, ...rest } = c;
    out.push({ ...rest, description, descriptionNote });
  }
  // Most recent first (spec §3); undated last, keeping the order they were found.
  return out.map((c, i) => ({ c, i })).sort((a, b) => (b.c.date ?? "").localeCompare(a.c.date ?? "") || a.i - b.i).map(({ c }) => c);
}
```

```ts
/** Runs inside the Inngest job (AGENTS.md rule 2 exception). Re-running replaces the brand's proposed campaigns. */
export async function runCampaignsStep(brandId: string, log: ResearchLog): Promise<void> {
  const [{ name, brandDomains }, selections] = await Promise.all([
    loadResearchPages(brandId),
    prisma.selection.findMany({ where: { brandId, field: { in: ["website", "instagram"] } }, include: { candidate: true } }),
  ]);
  const site = selections.find((s) => s.field === "website")?.candidate?.value ?? null;
  const ig = selections.find((s) => s.field === "instagram")?.candidate;
  const input = {
    brand: name,
    site: site ? new URL(site).hostname.replace(/^www\./, "") : null,
    brandDomains,
    instagram: ig ? { handle: ig.value, posts: ((ig.evidence ?? {}) as IgEvidence).recentMedia ?? [] } : null,
  };

  const campaigns = await researchCampaigns(
    input,
    {
      search: (prompt, l) => askWithSearch(prompt, { what: `${name}'s campaigns`, effort: "low", log: l }),
      write: askPlain,
      fetchPage,
      checkImage: (url) => checkImageUrl(url, "campaign"),
    },
    log,
  );

  await prisma.$transaction(async (tx) => {
    await tx.campaign.deleteMany({ where: { brandId } });
    for (const [i, c] of campaigns.entries()) {
      await tx.campaign.create({
        data: {
          brandId,
          position: i + 1,
          title: c.title,
          description: c.description,
          sourceUrls: { date: c.date, note: c.descriptionNote, urls: c.sources },
          status: "proposed",
          images: {
            create: c.images.map(({ candidate, verdict }) => ({
              url: candidate.url,
              sourceKind: candidate.source.kind === "third_party" ? "third_party" : "brand",
              width: candidate.check.width ?? null,
              height: candidate.check.height ?? null,
              score: verdict.score,
              reason: verdict.reason,
              selected: candidate === c.chosen,
            })),
          },
        },
      });
    }
  });
}
```

## Adjustments after the live runs (2026-10-21)

- **A source must be about the campaign**, not just load: invented URLs often return 200 with a generic page (Musinsa's newsroom index, an empty shell). `pageMentions` keeps a page only when its text names the brand and a distinctive word of the title; the log says "its source pages don't mention it".
- **Instagram posts only add images**; a caption match alone no longer keeps a campaign. Matching ignores seasons and generic words and needs half of the title's distinctive words.
- **Descriptions never guess**: the prompt forbids hedges ("likely", "presumably") and asks for an empty string when the page gives fewer than two facts; skipped descriptions are asked for once more.
- **Search**: an unreadable or empty answer falls through to Gemini, and the campaign search is tried twice.
- **Titles calling themselves a sale or promotion are dropped** (spec §3), whatever the model returns.
